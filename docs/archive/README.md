These files are **historical** working documents from overnight development
sessions. They describe goals as they were stated *before* the work happened
and are kept only for traceability — they are not current documentation.

- `goal_hypergery_v08_full_overnight.md` — the v0.8 overnight roadmap
  (originally `goal.md`). v0.8 was completed and closed on `develop`.
- `GOAL_V09_V10_MONSTER.md` — the v0.9 → v1.0 "monster" goal for the
  2026-06-05/06 overnight session. The outcome is recorded in
  `RESUMEN_EJECUTIVO_SESION.md`, `V09_REPORT.md`, `V10_REPORT.md`, and
  `FINAL_V09_V10_HANDOVER.md` at the repo root.

For current state, always start from `README.md` and `CHANGELOG.md`.
